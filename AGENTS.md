# Repository guide

This is a static website made of plain HTML, CSS and SVG. The deployable files
are in `public/`; there is no generator, JavaScript framework or build step.

Read [development and deployment](docs/generated/development.md) for preview
commands, CI behavior and Cloudflare Pages configuration. Keep that document
in sync with the repository when those details change.

Run `python3 scripts/check.py` after changes to verify the static site.
Keep `README.md` limited to the site name and homepage link.
